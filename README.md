# 油橄榄品种长期试验

管理油橄榄品种从引种、田间试验到本地推广的长期证据。

## 领域资料

`contracts/domain.schema.json` 规定共享资料结构，`fixtures/domain.json` 保存不含真实个人信息的示例。当前参与方包括产业技术人员、油橄榄企业、实验室人员、产业协会。

资料所依据的领域事实如下：

- 企业以三年为周期开展了五轮品种试验，十余年持续积累生长、病虫害、挂果时间、产量和含油率数据
- 比较指标包括适应性、抗病虫害、挂果时间、产量和含油率
- 长期试验筛选出适应当地环境的品种
- 技术员按季节在现场记录生长、病虫害和挂果等田间事实
- 原种来源、试验代次、地块处理、树株谱系、农事措施、采样方法、实验室结果与淘汰决定保持稳定关联
- 产业协会在金堂推广某一品种时，须说明它经历了哪些三年周期、在哪些地块表现稳定以及仍有哪些不确定性，而不是只给出最新年度排名

资料必须遵守的约束如下：

- 嫁接、补种和管理变化会破坏直接可比性，须标注并限定可比较范围
- 缺测、暴雨或干旱等异常气候、样本重测、地块拆分、树株死亡和指标定义调整均保留原始记录，并限定可比较范围
- 统计人员依据保留的原始记录和可比较范围，能够重现任一轮筛选

## 本地校验

仓库内的读取模块负责校验示例资料的领域标识、版本、参与方、事实和约束。运行项目自带测试即可检查这些基础资料能够稳定读取。仓库不保存账号、密钥、连接串或真实身份信息。
